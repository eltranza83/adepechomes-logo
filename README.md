# Adepec Homes Logo Assets

This repository contains the official, high-resolution vector logo assets for **Adepec Homes**. These files are optimized for digital use, print layout, and apparel embroidery (e.g., hats, shirts, and merch).

## Files Included

### 1. `logo-light-bg.svg`
* **Best Used For**: Light/white caps, light-colored T-shirts, light stationery, and light digital backgrounds.
* **Colors**: Gold A-frame logo symbol and horizontal lines, with **Dark Charcoal (`#0A0A0A`)** typography for readability.

### 2. `logo-dark-bg.svg`
* **Best Used For**: Black/dark caps, dark-colored hoodies, dark banners, and dark digital backgrounds.
* **Colors**: Gold A-frame logo symbol and horizontal lines, with **Pure White (`#FFFFFF`)** typography for readability.

### 3. `logo-light-bg-slit.svg`
* **Best Used For**: Light/white caps, light-colored T-shirts.
* **Feature**: Same as the light-theme logo, but with the **house symbol's bottom slit widened to 4.5px** to visually balance with the outer spacing.

### 4. `logo-dark-bg-slit.svg`
* **Best Used For**: Black/dark caps, dark hoodies.
* **Feature**: Same as the dark-theme logo, but with the **house symbol's bottom slit widened to 4.5px** to visually balance with the outer spacing.

### Typography
* **Primary Font**: `Syne` (Bold / Heavy weight)
* **Secondary Font**: `Syne` (Medium / Expanded weight)
* *Note: The vector SVG files load the Syne font from Google Fonts dynamically, but print shops can convert them directly to raw outlines for embroidery.*

## Embroidery & Printing Guidelines (For Caps & Merch)

If you are getting caps embroidered (like the mockups):

1. **Send the SVG directly**: Provide the `.svg` files from this repo to the embroidery vendor. They can scale them without losing quality.
2. **Digitization**: The shop will convert the SVG into a stitch file (usually `.DST` or `.PES` format).
3. **Thread Mapping**:
   * **House Symbol & Lines**: Request **Champagne Sandstone Thread** or warm gold matching `#C8B69A`.
   * **Text ("ADEPEC HOMES")**: Use **White Thread** on black/dark caps, and **Black Thread** on white/light caps.
